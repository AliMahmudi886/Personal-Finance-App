# Product roadmap

1. **Essential quality**
   Contain public Git history exposure, then approve a ledger precision and currency policy before migrating historical records. The current cycle introduces an accessible shared shell, paginated expense search and readable display of forecast amounts.
2. **Premium experience**
   The current dashboard ships period controls, ledger totals and comparisons, recent activity and quick entry. Next, add structured transaction filters, reviewed edit workflows, and account-aware budgeting after ledger dependencies are settled.
3. **Advanced financial capabilities**
   Introduce goal contributions and dates, recurring payment management with idempotent posting, dedicated reporting and reviewed export. Validate model quality and move expensive model fitting off interactive requests.
4. **Product excellence**
   Add dashboard preferences, onboarding refinements, assistive-technology verification and representative performance budgets. Verify staging backup and recovery before production rollout.
